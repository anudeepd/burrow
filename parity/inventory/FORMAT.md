# parity/inventory — file formats (binding for all inventory authors)

Everything here is derived from the Hadoop 3.4.3 **sources** (extracted by `tools/extract-sources.sh` into
`.cluster/src-extract/<module>/…`) — not from memory. Every record carries a `source: "<relative path>:<line>"`
pointer (relative to `.cluster/src-extract/`, e.g. `hadoop-yarn-server-resourcemanager/org/apache/hadoop/yarn/server/resourcemanager/webapp/AboutBlock.java:44`).
Labels / column titles are **verbatim** (copy the Java string literal; keep trailing `:`, spaces, case). When a label is built
dynamically (`join("Application ", id)`), write the template and mark `dynamic: true`.

## Layout

```
parity/inventory/
  FORMAT.md              this file (binding)
  schema.json            JSON Schema (draft 2020-12) for every file below; validate.py selects one $def
  validate.py            .venv/bin/python parity/inventory/validate.py  (schema + referential integrity + class
                         accounting + totals; exit 1 on failure)
  build.py               merges src/rest-*.yaml -> rest-schema.yaml ; src/legacy-*.yaml -> legacy-pages.yaml ;
                         builds field-ids.yaml ; (idempotent)
  tools/                 extract-sources.sh, extract_dao.py, rest_rm_objects.py, gen_rest_rm.py, gen_rest_nm.py,
                         ui2_extract.py, ui2_decode_templates.js, gen_parity_doc.py, invlib.py
  src/rest-rm.yaml       RM REST objects/resources/entities         (generated by tools/gen_rest_rm.py + hand-written
                         FIELD_META in that script)
  src/rest-nm.yaml       NM REST + NM legacy UI support types       (generated by tools/gen_rest_nm.py)
  src/rest-daemon.yaml   /conf /jmx /stacks /logs /logLevel, log-serving endpoints (NM/AHS/JHS), web-proxy
  src/rest-ats.yaml      UI2-only ATS v2 / YARN Services endpoints (out of product scope; declared so ui2 pages
                         reference a real resource id)
  src/field-overrides.yaml  normaliser/format/unit/waiver overrides, prefix `groups`, `extraFields`, `unmappedPaths`
  src/legacy-*.yaml      legacy Hamlet UI part files (one file per page group; RM parts by lead).  NOT yet written:
                         src/legacy-other.yaml (the NM/AHS/JHS legacy pages) - the P0 acceptance for this slice is
                         the RM webapp package plus the RM daemon tools pages, which are all covered
  legacy-pages.yaml      GENERATED merge of src/legacy-*.yaml (do not hand-edit)
  ui2.yaml               UI2 (Ember) in-scope routes/pages/items
  ui2-extra.yaml         UI2 (Ember) out-of-scope routes (ATS v2/flow/services) - honest catalogue, no per-field depth
  rest-schema.yaml       GENERATED merge of src/rest-*.yaml (do not hand-edit)
  field-ids.yaml         GENERATED registry (do not hand-edit; edit src/field-overrides.yaml)
```

## Build & validate

```sh
.venv/bin/python parity/inventory/build.py      # merge + registry (idempotent)
.venv/bin/python parity/inventory/validate.py   # gate: schema + referential integrity + totals
```

`build.py` fails hard on duplicate entity/object/resource/derived ids (the field-id grammar depends on them being
unique repo-wide). `validate.py` fails on: schema violations, an item `field:` with no registry row, a `rest.resource`
that does not exist, a page id being referenced by `includes:` but not declared, a waivable row without a reason, a
required row carrying a waiver, an item id not prefixed by its page id, and any `*Block.java`/`*Page.java`/`*Table.java`
in the RM webapp package that is neither referenced by a page nor listed (with a reason) in validate.py's
`EXCLUDED_CLASSES`. Every REST JSON path reached from a GET resource response must be registered or waived in
`field-ids.yaml:unmappedPaths`; there are no silent skips.

## Field ids (see docs/contracts/parity-dom.md)

`<entity>.<path>`; `path` = JSON key path **relative to the entity object**, dot-separated, array indices dropped (an id
NEVER contains `[]` or a numeric index — the `field-ids.yaml` registry is the authority and `validate.py` rejects an
item id that is not a registry row), map keys written `*`. Containers (objects/arrays of objects) have no id; only
**leaf** values do (string/number/boolean/enum/any).

**Composite ids (the one exception).** When YARN prints a whole `Resource`/object as a single formatted string
(`"<memory:1024, vCores:2>"`, `format: resource-string`) that cell is a datum of its own and gets an id for the
container path (`queue.resourcesUsed`, `queueuser.AMResourceLimit`, `scheduler.maximumAllocation`, …), flagged
`composite: true` in the registry, with the primitive leaf ids underneath kept canonical. The SPA stamps both the
composite cell and the nested primitive datums.

Derived (non-REST) values: `<entity>.derived.<camelName>` and are declared in a `derived:` list (see below) in the file
that first needs them; one declaration per id repo-wide (reuse across files by id). A REST part may also carry a
`derived:` list (for values the product computes from REST keys even when no legacy page shows them).

Entities are declared in `entities:` of a rest part (see below). A nested object whose class is the root object of **another**
entity (e.g. queue -> `queues.queue[]` elements, app attempts) is *not* flattened into the parent: it is its own entity.

## REST parts (`src/rest-*.yaml`)

```yaml
entities:                       # field-id prefixes introduced by this part
  - id: app
    description: one YARN application (RM)
    roots: [{object: AppInfo, jsonPath: "apps.app[]", when: []}]   # root object(s); several for polymorphic roots
    # jsonPath is the ABSOLUTE path of the object in the RESPONSE BODY; "" means the object IS the body root
    # (root-unwrapped responses).  A root may be declared per runtime subclass (Capacity/Fair/Fifo scheduler infos
    # all sit at "scheduler.schedulerInfo").  `roots: []` is allowed for an entity that has no REST endpoint at all
    # (e.g. usermetrics: JMX only).
objects:                        # DTOs; unique object names repo-wide (prefix NM/Ahs/Hs when a name clashes)
  AppInfo:
    java: org.apache.hadoop.yarn.server.resourcemanager.webapp.dao.AppInfo
    source: "…/AppInfo.java:60"
    extends: null               # object name or null; parent fields are inherited (listed once, in the parent)
    xmlRoot: app                # @XmlRootElement name (JSON wrapper key when it is a top-level response) or null
    xmlType: null               # @XmlType name (the JAXB polymorphism discriminator value) or null
    accessType: FIELD           # effective @XmlAccessorType
    jsonMode: wrapped           # wrapped | unwrapped | unwrapped-stringified | nested  (live-verified; see docs/parity.md §3.3)
    rootUnwrapping: false       # == jsonMode != wrapped
    note: ""
    fields:
      - name: allocatedMB       # JSON key exactly as serialised (JAXB rules: @XmlElement(name=..), bean property names for
                                # FIELD vs PROPERTY access, @XmlTransient excluded, @JsonProperty if Jackson provider)
        type: int               # string|int|long|float|double|boolean|enum|object|map|any
        array: false            # true => JSON array of `type`
        ref: null               # object name when type=object (or map/array of objects)
        values: []              # enum constants when type=enum
        nullable: false         # key may be absent or null in practice (explain in note/when)
        when: []                # presence conditions: scheduler=capacity|fair|fifo · state=RUNNING · conf:yarn.foo=true · labels · ha …
        unit: MB                # optional: MB|GB|ms|epoch-ms|seconds|percent|count|bytes|MB-seconds|count/s|…
        source: "…/AppInfo.java:123"
        note: "free text (e.g. -1 when unavailable)"
        # provenance keys kept from the parser (optional): javaName javaType origin access init annotations
        # mapKey mapValue enumType.  `synthetic: true` marks a field injected by the JSON provider (JAXB `type`).
resources:
  - id: rm.apps                 # unique, `<daemon>.<name>`
    daemon: rm                  # rm|nm|ahs|jhs|proxy|common
    method: GET
    path: /ws/v1/cluster/apps
    contractPath: apps          # the `/api/yarn/{path}` form from docs/contracts/api.md §3, or null if not in the contract
    allowlist: true             # inside docs/contracts/api.md §3 / §3 NM / daemon lists (true) | false (exists, not in contract)
    readOnly: true              # false for POST/PUT/DELETE (listed, excluded from the product)
    params:
      - {name: states, in: query, type: string, required: false, values: [], doc: "comma separated YarnApplicationState", source: "RMWebServices.java:700"}
    produces: [application/json, application/xml]
    response: {object: AppsInfo, jsonRoot: apps, shape: '{"apps":{"app":[ … ]}}', contentType: application/json}
    errors: [{status: 404, when: "unknown app", body: RemoteException}]
    when: []                    # resource only exists under conditions (e.g. conf)
    acl: ""                     # authorisation notes (admin/queue ACL/user filter)
    source: "…/RMWebServices.java:900"
    note: ""
```
JSON shape matters: RM/NM/AHS/JHS use a `JAXBContextResolver` + Jersey; document single-element-array quirks, `rootUnwrapping`,
which root key wraps the body, and `Content-Type`. For non-JSON endpoints (`/stacks`, `/logs`, containerlogs) set `response.contentType`
and describe the body in `response.shape`, with `object: null`. Set `response.rootUnwrapping: false` only when the body is
wrapped; when it is not, the object's `jsonMode` says so and `validate.py`/`build.py` derive the id paths from it.

## Pages (`legacy-pages.yaml`, `ui2.yaml`)

```yaml
version: 1
derived:                        # derived field declarations (optional per file)
  - {id: app.derived.elapsedText, entity: app, type: string, format: duration-hms, from: [app.elapsedTime], derivation: "Times.format(...)", source: "…:77"}
pages:
  - id: legacy.app                       # unique; `legacy.<slug>` or `ui2.<slug>`
    daemon: rm                           # rm|nm|ahs|jhs|proxy
    route: /cluster/app/{appId}          # URL pattern (RMWebApp route table for legacy; ember route path for ui2)
    title: "Application {id}"            # verbatim/templated page title
    classes: [RmController#app, AppPage, RMAppBlock, AppBlock]   # source classes (simple names), controller entry first
    when: []                             # page-level availability (scheduler=capacity, conf:…)
    sections:
      - id: legacy.app.summary
        title: "Application Overview"    # verbatim heading or null
        source: "…:90"
        when: []
        items:
          - id: legacy.app.summary.user  # unique repo-wide; MUST be prefixed by the PAGE id
            label: "User:"               # verbatim text shown to the user (null if none, e.g. a bare chart)
            dynamic: false               # true when label text is computed
            kind: kv                     # kv|column|metric|link|chart|button|nav|legend|title|text
            field: app.user              # canonical field id (MUST exist in the registry or be declared `derived`)
            fields: []                   # extra ids when one cell is composed of several (field = primary)
            rest: {resource: rm.app, path: "app.user"}   # where it comes from, or null for pure-derived
            derivation: ""               # REQUIRED if field is derived./composite: quote the Java expression
            format: none                 # vocabulary below (or other:<text>)
            normaliser: none             # vocabulary below
            nullDisplay: null            # text shown for null/-1 (e.g. "N/A", "UNASSIGNED", "")
            when: []                     # visibility conditions at item level
            scenario: ""                 # what must exist on the cluster to see this item
            source: "…/AppBlock.java:101"
            tooltip: null                # title="" attribute text when the cell has one (e.g. th title)
            restGap: false               # true => legacy shows it but NO REST field of the contracted/known endpoints supplies it
            note: ""
```
Page-level optional keys: `includes: [page ids]` (shared chrome/blocks rendered inside this page), `query: [{name, doc}]` (request params the page honours),
`titleDynamic: true`. `derived[]` rows may also carry `restGap: true` and `altSource` (text: where else the value can be obtained, e.g. `/jmx` bean).
`kind`: `kv` label+value pair · `column` table column header (one item per column) · `metric` number in a
metrics table · `link` hyperlink whose *target* is data · `chart` bar/progress/graph encoding a value · `button` action control ·
`nav` navigation entry · `legend` static legend/help text · `title` page/section title carrying data · `text` static prose.
Pure static chrome (no data) still gets an item with `field: static.<name>` (entity `static`, declared automatically, never a REST field).

`format` vocabulary: `none` · `html-escaped` · `byteDesc` (StringUtils.byteDesc) · `mb` (value is MB) · `mb-suffix` ("N MB") ·
`resource-string` (Resource.toString/`<memory:…, vCores:…>`) · `epoch-datetime` (Times.format) · `duration` (Times.format elapsed / StringUtils.formatTime) ·
`percent-1dp` (StringUtils.formatPercent(x,1) => "12.3%") · `float-1dp` ("%.1f", no % sign) · `percent-int` · `fixed-2` · `int` · `boolean` · `enum` · `progress-bar` · `join-comma` · `url` · `other:<text>`.
`normaliser` vocabulary (legacy-text -> raw): `none` · `mb` · `bytes-desc` · `epoch` · `duration` · `percent` · `na-as-null` ·
`resource-string` · `lowercase` · `int` · `trim` · `html-strip` · `boolean-text` · `enum-name` · `url` · `other:<text>`; combine with `+` (`na-as-null+epoch`).
`when` condition vocabulary: `scheduler=capacity|fair|fifo` · `state=<YarnApplicationState|RMAppAttemptState|RMNodeState…>` ·
`conf:<yarn property>=<value>` · `labels` · `ha` · `secure` · `value:null` / `value:-1` / `value:non-empty` · `ui:<flag>` · free text after `other:`.

## Registry rows (`field-ids.yaml`, generated)

```yaml
- id: app.allocatedMB
  entity: app
  path: allocatedMB
  origin: rest            # rest | derived | static
  rest: [{resource: rm.apps, jsonPath: "apps.app[].allocatedMB"}]
  type: int
  unit: MB
  nullable: false
  when: []
  shownBy: [legacy, ui2]  # subset of legacy|ui2|rest-only ; rest-only iff nobody shows it
  legacyItems: […]  ui2Items: […]
  format: mb              # from the first consuming item (override in field-overrides)
  normaliser: mb
  status: required        # required | waivable
  waiver: {category: internal|deprecated|secret|rendered-elsewhere|unused-by-any-ui|write-only|other, reason: "…"}   # iff waivable
  composite: true         # (optional) a Resource object rendered as one formatted string; see "Composite ids"
  synthetic: true         # (optional) JAXB-injected `type` discriminator
  derivation: "…"         # (optional, derived rows) the Java/JS expression
  altSource: "…"          # (optional) where else the value can be obtained (/jmx, another endpoint, "none")
```

`status` is computed, not hand-edited: an id some item renders is `required`; otherwise it is `waivable` and **must**
carry a `waiver.reason` — either from `src/field-overrides.yaml` (`fields.<id>.waiver`, or a prefix `groups[]` entry) or
the builder's defaults (`rendered-elsewhere` when the id feeds a declared derived value or sits inside a required
composite cell; `write-only` when only write endpoints expose it; `internal` for synthetic discriminators; otherwise
`unused-by-any-ui`).

The registry also carries `unmappedPaths:` — REST JSON paths (from a GET resource response) that deliberately get **no**
field id, each with `{resource, path, waiver:{category, reason}}`. `build.py` fills in `rendered-elsewhere` automatically
when the same key is registered through another resource/root, and takes the remaining entries from
`src/field-overrides.yaml:unmappedPaths`. `validate.py` fails if a reached path is missing from that list.

`src/field-overrides.yaml` may also declare `extraFields:` for ids no JSON walk can discover (XML-shaped daemon
responses such as `/conf`, scraped HTML listings such as `/logs`, dynamic JMX attribute names, UI2 client-side model
fields). Each entry needs `entity`, `rest:`, `note` and states why the walk cannot see it.
